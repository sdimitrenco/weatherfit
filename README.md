# weatherfit

Telegram-бот, который каждое утро присылает прогноз на день: почасовой список,
ветер с оценкой силы, осадки, вердикт «нужна ли защита от дождя» и совет, как
одеться. Данные берутся из [Open-Meteo](https://open-meteo.com), без API-ключа.

Бот многопользовательский: любой, кто нажал `/start`, подписывается сам и
дальше настраивает под себя город, время рассылки, единицы ветра и язык.
Интерфейс на английском, русском и немецком, язык подхватывается из Telegram.

## Кнопки и команды

Под полем ввода всегда четыре кнопки: «Сейчас», «Сегодня», «Завтра»,
«Настройки». То же доступно командами:

| Команда | Что делает |
|---|---|
| `/now` | погода на текущий момент |
| `/today` | отчёт с текущего часа до конца активного окна |
| `/tomorrow` | отчёт на завтра, все активные часы |
| `/settings` | город, время, единицы, язык, пауза |
| `/city Прага` | сменить город; без аргумента бот спросит название или геопозицию |
| `/time 06:30` | сменить время утренней рассылки |
| `/units` | переключить м/с и км/ч |
| `/language` | выбрать язык |
| `/pause`, `/resume` | остановить и вернуть утреннюю рассылку |
| `/stop` | отписаться |
| `/stats` | число подписчиков, только для админов |

Город можно задать названием (поиск через Open-Meteo Geocoding, бот покажет
варианты кнопками) или кнопкой «Отправить геопозицию»: таймзона определится
сама.

## Запуск

```bash
cp .env.example .env
$EDITOR .env            # как минимум TELEGRAM_BOT_TOKEN
docker compose up -d --build
```

Локально без Docker:

```bash
make run
```

Подробности про сервер, бэкап и обновление: [DEPLOY.md](DEPLOY.md).

## Конфигурация

Все переменные с примерами лежат в [.env.example](.env.example). Обязательна
одна: `TELEGRAM_BOT_TOKEN`. Остальные задают настройки нового подписчика и
режим работы.

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | — | токен от @BotFather |
| `TELEGRAM_ALLOWED_CHAT_IDS` | пусто | если задан, бот приватный |
| `TELEGRAM_ADMIN_CHAT_IDS` | пусто | кому доступна `/stats` |
| `LOCATION_NAME`, `LOCATION_LAT`, `LOCATION_LON` | Дрезден | город нового подписчика |
| `TZ_NAME` | `Europe/Berlin` | таймзона нового подписчика |
| `REPORT_TIME` | `07:00` | время утренней рассылки |
| `ACTIVE_HOURS` | `07-22` | часы в отчёте и в расчёте советов |
| `WIND_UNIT` | `ms` | `ms` или `kmh` |
| `DEFAULT_LANG` | `en` | язык, если Telegram его не прислал |
| `HOURLY_LAYOUT` | `lines` | `lines` или `table` |
| `DB_PATH` | `data/weatherfit.db` | файл SQLite |
| `LOG_LEVEL`, `LOG_FORMAT` | `info`, `json` | логи |

Конфигурация проверяется при старте: все ошибки печатаются списком, потом
процесс завершается с кодом 1.

## Архитектура

Clean Architecture: бизнес-логика не знает ни про Telegram, ни про HTTP, ни
про язык интерфейса.

```
cmd/weatherbot/          сборка зависимостей, graceful shutdown
internal/
  config/                загрузка и валидация env
  domain/                Forecast, Subscriber, правила ветра, осадков, одежды
  i18n/                  каталоги en/ru/de и перевод доменных структур в текст
  usecase/               сборка отчёта, рассылка с ретраями, подписки
  port/                  ForecastProvider, SubscriberStore, Geocoder, Notifier, Clock
  adapter/
    openmeteo/           клиент Forecast API
    geocode/             поиск городов
    store/sqlite/        подписчики и настройки
    render/              Report → Telegram HTML
    scheduler/           минутный тик рассылки
    telegram/            команды, кнопки, whitelist
testdata/                фикстуры Open-Meteo и golden-файлы рендера
```

Домен возвращает не текст, а структуры с ключами перевода: `HeadlineRainCoat`,
`AdviceWindproofGusts`, `ConditionThunderstorm`. Поэтому новый язык это один
файл каталога в `internal/i18n`, без правок правил. Полнота каталогов и
совпадение числа подстановок проверяются тестом.

Время: у каждого подписчика своя таймзона, планировщик просыпается раз в
минуту и спрашивает у домена, кому пора. Переход на летнее время работает,
потому что «07:00» считается через `time.Date` в таймзоне подписчика, а не
прибавлением 24 часов.

## Разработка

```bash
make test        # тесты
make test-race   # тесты с детектором гонок
make lint        # golangci-lint
make build       # бинарник в bin/
```

Golden-файлы рендера обновляются так:

```bash
go test ./internal/adapter/render/ -run Golden -update
```

Тесты не ходят в сеть: ответы Open-Meteo лежат в `testdata`, Telegram API
подменяется `httptest`-заглушкой, время подменяется через интерфейс `Clock`.
